# v0.72.0 · 更轻盈的园丁与协作布局

本版集中优化园丁、引用和材料整理体验，作为 macOS 通用预发布版提供实际试用。旧版本下载保留。

## 主要变化

- 园丁更简洁：精简动作、引用、任务和实验中的重复说明，减少不必要的信息展示，调整控件对齐与间距。
- 引用更顺手：输入 `@` 自动打开材料目录，可按关键词搜索；已引用的材料以紧凑胶囊呈现，相关菜单更轻巧。
- 动作识别更准确：引用的卡片、页面标题即使包含“变异”“碰撞”等动作词，也不会仅因此被识别为动作指令。
- 画布阅读修复：改善资源卡片外观，修复点击卡片后阅读窗口未正常打开的问题。
- 实验返回更清楚：“返回路径图”按钮增加高亮，方便从实验详情回到路径图。
- 工作集与园丁可同时打开：材料整理和对话并排使用，随窗口宽高调整布局，减少遮挡与拥挤。

本版延续 0.70.0 的界面与交互更新，不包含单独测试的 0.71.0 存储功能。
