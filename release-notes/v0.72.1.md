# v0.72.1 · 存储与创作体验完整整合

本版累积包含 **0.71.0 的存储升级与 0.72.0 的全部界面优化**，作为 macOS 通用预发布版提供实际试用。App 名称保持“沙盒工作台”，旧版本下载保留。

## 主要变化

- 记录更完整：整合旧任务记录的兼容恢复、历史输入与成果复用，以及受保护的存储维护。
- 手记衔接更顺畅：主页面、浮窗和独立手记窗口均可保存并加入工作集，保存或加入失败时保留内容以便继续处理。
- 园丁更轻巧：精简动作、引用、任务与实验中的重复说明；已引用的材料以胶囊呈现，输入 `@` 可按关键词查找材料。
- 动作识别更准确：引用标题和历史材料中的“变异”“碰撞”等词不会误当作本轮指令；从历史准备草稿时保留已打开的工作集。
- 整理与阅读更舒适：工作集和园丁侧栏可以同时打开；修复画布资源卡片的阅读入口，并高亮实验详情的“返回路径图”。
