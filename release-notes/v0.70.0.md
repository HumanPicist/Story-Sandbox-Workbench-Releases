# v0.70.0 · macOS 通用未公证版

本版是累积开发成果的公开预发布快照，主要更新创作工作区、内容保护与园丁引用体验。版本从本地 0.68.0 直接更新为 0.70.0；旧版本下载保留。

## 主要变化

- 统一创作工作区：中央阅读、编辑、专注和比较配合园丁侧栏；改善窄窗、短窗和画布布局，简洁画布卡片的标题独占一行。
- 内容保护：编辑期间检测外部修改，无法无损保存的内容拒绝覆盖并保留原件与草稿；改善手记多窗口的收回提示、保存显示和缩放下的正文编辑。
- 中文输入：修复园丁输入中文拼音时，确认候选的回车误触发发送；已在隔离原生窗口中实测搜狗拼音，其他输入法仍需继续验证。
- 工作集材料卡：整理一组材料后，可附加为折叠引用卡片，保留园丁正文草稿；卡片可展开、移除、返回编辑，发送时冻结材料快照。
- 自由选段引用：在检视器、手记阅读及园丁对话中选中文字，点击“引用到园丁”或按 ⌘⇧U，将选段附加为独立材料块，再随自己的正文发送。引用保留来源，可返回定位；来源歧义或缺失时会明确提示。
- 园丁对话：保存讨论提升到一级入口；任务记录默认收起，按需查看结果和详情；打开未读会话或点击已打开的对话记录区，可清除当时已有的未读提示。
- 首页与细节：减少重复滚动容器，改进阅读工具栏、菜单、焦点和长文本显示。

引用材料本身不会自动成为执行指令或写入授权。新版本继续保留直连/审核模式、保存与草稿、历史、任务队列和沙盒归属保护。
