# v0.59.0 · Mature Experience

本版完成 Mature Experience 全阶段升级：统一视觉与空间语义、原生手记窗口、可见代称解析、资料与笔记本生命周期、完整 Markdown 源码编辑、显式关系图、活动与撤销、快捷键/IME 保护，以及综合故障恢复和长期运行硬化。

## 主要变化

- 手记支持 Source/Reading、源码行槽块移动、格式工具、自动保存、恢复稿、外部 revision 冲突与唯一编辑租约。
- 手记可以脱离为 macOS 原生窗口，并保留跨窗口状态、附件、置顶和最小权限边界。
- 资料代称、编号、标题、路径、alias 与显式 wikilink 使用统一可见解析；歧义或缺失不会自动猜选。
- 资料与笔记本提供可预览、可恢复、不中断链接身份的隐藏生命周期。
- 反向链接与局部关系图支持方向、1/2 跳、节点拖动、平移/缩放、键盘等价入口和生命周期状态。
- 工作台统一导航、三栏空间、页头、状态、空态、错误恢复、活动与撤销及快捷键发现。
- macOS 主窗口保留红黄绿系统按钮和可拖动暖色顶部边缘栏；活动面板与 Toast 已适配顶部安全区。
- 增加窗口、磁盘、revision、索引、权限和 Agent 进程六类故障保护，以及500轮长期运行验证。
